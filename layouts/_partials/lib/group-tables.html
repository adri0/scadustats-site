{{- /* Input: dict {season_id, groups, bracket} where groups is a data/groups/season-.yaml entry and bracket the matching data/brackets/season-.yaml entry (or nil). The sort is stable, so ties keep the curated (final placing) order of the YAML. Points are games won, unless the groups file says `scoring: points` (Season 3): then a match's for/against are the points each side scored in its games (a square each, two more per line), and a row's points add up the points it scored. $s.player_blue).slug -}} {{- $redFor := $s.red_score }}{{ $blueFor := $s.blue_score -}} {{- if $byPoints -}} {{- $redFor = 0 }}{{ $blueFor = 0 -}} {{- range $s.games }}{{ $redFor = add $redFor (dict "player" $p "points" $pts "w" $w "d" $d "l" $l) -}} {{- end -}} {{- $groups = $groups | append (dict "name" $g.name "rows" (sort $rows "points" "desc")) -}} {{- end -}} {{- return (dict
